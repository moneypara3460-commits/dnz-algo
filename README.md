# DNZ ALGO V2.2 Web

DNZ ALGO V2.1'in geliştirilmiş sürümü.

## Desteklenen varlıklar

- Binance kripto pariteleri
- XAU/USD (Altın / ABD Doları)

## XAU/USD veri kaynağı

XAU/USD verisi Twelve Data üzerinden alınır. Uygulamada Twelve Data API Key girilerek 5 dakikalık ve 15 dakikalık veriler kullanılabilir.

## Çalıştırma

```bash
pip install -r requirements.txt
streamlit run app.py
```

## Deploy

GitHub repo köküne `app.py` ve `requirements.txt` koyup Streamlit Community Cloud üzerinden deploy edilebilir.
